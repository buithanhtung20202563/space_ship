## Installer
### Arch Linux
```
  sudo pacman -S sfml make cmake gcc
```
## Build_and_run
```
  git clone https://github.com/buithanhtung20202563/space_ship.git
  cd space_ship && mkdir build && cd build
  cmake ../ && make -j4
  ./space_ship
```
